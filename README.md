# BD 2026.1 - PPGTI - Exemplos da Disciplina

Este diretório reúne exemplos práticos usados ao longo da disciplina. A ideia é concentrar materiais curtos, executáveis e organizados por aula ou tema, facilitando tanto a demonstração em sala quanto a consulta posterior.

## Objetivo

Os exemplos deste repositório servem para:

- ilustrar conceitos vistos em aula com código executável;
- oferecer uma base para experimentação e adaptação;
- manter os materiais separados por assunto, com contexto e instruções próprias.

## Exemplos disponíveis

### `aula-04-streaming-varejo`

Exemplo de streaming de eventos de varejo com Python e Redpanda/Kafka, incluindo:

- publicação e consumo de eventos;
- processamento em camadas inspiradas em `Bronze`, `Silver` e `Gold`;
- geração de arquivos para inspeção dos dados processados.
